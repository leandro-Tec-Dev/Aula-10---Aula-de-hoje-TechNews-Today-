TechNews Today 📰
📋 Descrição

O TechNews Today é um portal de notícias sobre tecnologia desenvolvido como atividade de Desenvolvimento Web, utilizando HTML5 semântico e CSS3. O projeto demonstra como as tags HTML podem ser utilizadas para organizar o conteúdo de uma página e como o CSS é responsável pela sua aparência.

🎯 Objetivo

O objetivo da atividade é praticar a criação de uma página web organizada e semântica, utilizando diferentes elementos do HTML, além de aplicar estilos com CSS para melhorar a apresentação visual do site.

🛠️ Tecnologias Utilizadas
HTML5 — estrutura e organização do conteúdo.
CSS3 — cores, fontes, espaçamentos, tamanhos e layout.
📌 Funcionalidades

O site possui:

📰 Cabeçalho com nome e slogan;
🚀 Notícia em destaque sobre inteligência artificial;
📅 Data da publicação;
📖 Área interativa de "Leia mais";
📺 Vídeo incorporado do YouTube;
📧 Formulário de newsletter;
🔗 Campos e botões para interação;
🦶 Rodapé com informações de contato;
📱 Estrutura adaptável para diferentes tamanhos de tela.

O material utiliza elementos como <header>, <main>, <article>, <section>, <details>, <summary>, <iframe>, <form> e <footer> para organizar essas áreas.

📁 Estrutura do Projeto
TechNews/
├── index.html
├── style.css
└── README.md

index.html: contém toda a estrutura e o conteúdo do portal.

style.css: contém os estilos responsáveis pela aparência da página.

README.md: apresenta a documentação e as informações do projeto.

▶️ Como Executar
Baixe ou copie os arquivos do projeto.
Coloque index.html e style.css na mesma pasta.
Abra o arquivo index.html em um navegador.
O portal será carregado automaticamente.
📚 Conceitos Trabalhados

Durante a atividade foram praticados conceitos de HTML semântico, organização de conteúdo, formulários, elementos interativos, incorporação de vídeos e estilização com CSS. O projeto também trabalha a importância de utilizar cada tag de acordo com sua função.
